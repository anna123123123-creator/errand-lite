# 同城跑腿系统（精简开源版）· Errand Lite

**[在线体验（客户端）→](https://anna123123123-creator.github.io/errand-lite/)** · **[跑腿员/运营后台 →](https://anna123123123-creator.github.io/errand-lite/admin.html)**

免费开源的同城跑腿系统精简版。这不是截图或原型图，是一个**真实可用**的下单/接单系统：客户发布跑腿需求（取快递、代买、送文件、排队代办……）并设置悬赏金额，后台指派跑腿员接单、送达后自动结算收入——都是真功能，纯前端 + `localStorage` 实现，不需要服务器、不需要数据库，克隆下来打开就能用，也适合作为学习或二次开发的起点。

![screenshot](screenshot.png)

## 功能

**客户端（发单方视角）**
- 发布跑腿需求：类型、取件地址、送达地址、悬赏金额、期望完成时间、备注、联系方式，自动校验必填项
- 按手机号查询名下所有跑腿订单，实时查看状态（待接单 / 进行中 / 已送达）和已分配的跑腿员

**跑腿员/运营后台**
- 仪表盘：订单总数、待接单数、进行中数、本月已送达总收入（按送达时间实时计算），跑腿员排行榜（已完成单数、累计收入，真实从订单记录聚合，非存储计数器）
- 接单大厅：为待接单订单指派跑腿员（若订单在指派时已被抢先接单，会重新校验最新状态并拒绝，提示"已被抢先接单"）；进行中订单可一键标记"已送达"
- 我的跑腿员：跑腿员名单的新增、编辑、删除
- 订单管理：全部订单列表，按状态筛选，显示已分配的跑腿员

## 试用方法

克隆下来，直接用浏览器打开 `index.html`，或用静态文件服务器跑起来：

```bash
python3 -m http.server 8000
```

客户端在 `index.html`，跑腿员/运营后台在 `admin.html`。所有数据存在浏览器的 `localStorage` 里（`errand_lite_data_v1` 这个 key），后台侧边栏有"重置示例数据"按钮可以随时清空重来。

## 技术说明

没有用任何框架或构建工具，纯原生 HTML/CSS/JavaScript，一共 5 个文件：`data.js`（数据层，负责 localStorage 读写、种子数据和跑腿员统计聚合）、`index.html` + `script.js`（客户端）、`admin.html` + `admin.js`（跑腿员/运营后台）。

因为是纯前端 Demo，数据只存在当前浏览器里，不同设备/浏览器之间不会同步；也没有真实的地图导航、GPS 定位、即时通讯功能，跑腿员之间的接单也没有推送提醒。真实生产系统需要一个后端 API + 数据库来替换 `data.js` 里的存储层，并补上支付、即时通讯、地图导航等能力，界面和交互逻辑基本可以直接复用。
